FluidJson
=========

![badge][badge-ios]
![badge][badge-jvm]

A JSON manipulation library for Kotlin


Setup
-----

Add the following to your `build.gradle` file:

```kotlin
dependencies {
    implementation("net.mready.json:fluidjson:1.0.1")
}
```
